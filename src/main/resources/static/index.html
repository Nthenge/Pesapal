README

        
Pesapal RDBMS Challenge is a lightweight web-based relational database engine built in Java. It allows users to execute SQL queries dynamically, visualize results, and practice CRUD operations.


        
Features

        
    
            
  • Dynamic execution of SQL queries.
    • 
            
  • Automatic detection of table names from queries.
    • 
            
  • Displays query results in a tabular format.
    • 
            
  • Stores the last accessed table for convenience.
    • 
            
  • Supports CREATE, SELECT, INSERT, UPDATE, DELETE, and basic JOIN queries.
    • 
        


        
Technologies Used

        
    
            
  • Frontend: HTML, CSS, JavaScript
    • 
            
  • Backend: Java, Spring boot
    •

Setup & Installation

        
    
            
  • Clone the repository: git clone <https://github.com/Nthenge/Pesapal.git>
    • 
            
  • Open it with IntelliJ: IDEA
    • 
            
  • Run maven install for dependencies: maven install
    • 
            
  • Open your browser at http://localhost:8080/index.html
    • 
            
  • or Use Docker
     
    
                
    
                    docker build -t pesapal-rdbms .
                
    
                
    
                    docker run -p 8080:8080 pesapal-rdbms
                
    
            
    • 
        


        
Usage

        
    
            
  • Type SQL commands in the input box on the left.
    • 
            
  • Click "Execute" to run the query.
    • 
            
  • Results will appear below the input box in a table.
    • 
            
  • Last accessed table is remembered for data-modifying commands.
    • 
            
  • 
                
    eg.
    
                
    Create Table
    
                    CREATE TABLE users (id INT PRIMARY KEY, name TEXT) 

    

                    Insert Data (auto-increment ID)
    
                    INSERT INTO users VALUES (, 'Alice') INSERT INTO users VALUES (, 'Bob')

    

                    Select Data
    
                    SELECT * FROM users SELECT * FROM users WHERE id = 1

    

                    Update Data
    
                    UPDATE users SET name = 'Mike' WHERE id = 1

    

                    Delete Data
    
                    DELETE FROM users WHERE id = 2

    

                    Join Query
    
                    SELECT * FROM orders JOIN users ON orders.user_id = users.id
